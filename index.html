🔑 Configurar API gratuita (RapidAPI)

Plano gratuito: 1000 requisições/mês – suficiente para monitorar 5 construtoras a cada 2 horas.
  1. Crie uma conta em RapidAPI (gratuito).
  2. Acesse o serviço "Instagram Scraper" (procure por "instagram-scraper-2025" ou similar com free tier).
  3. Assine o plano BASIC (Free) – 1000 requisições/mês.
  4. Copie sua API Key (na aba "Authorization").
  5. Cole abaixo e clique em "Salvar". O sistema fará buscas reais.

⚠️ Modo Demo gera posts fictícios e alertas a cada 2 minutos – ideal para testar o funcionamento.
